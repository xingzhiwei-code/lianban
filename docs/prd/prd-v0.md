# PRD-v0：跟练闭环

> 版本：v0（待确认）｜ 日期：2026-10-06
> 地位：练伴第一个可交付版本（HTML 原型验证后转正开发）
> 目标读者：编码 Agent——读完直接开工，不需要再问"这个功能到底要怎么做"
> 前置阅读：`docs/constitution.md`（宪法，最高优先级）、`docs/roadmap.md`、`docs/decisions/ADR-001.md`

## 1. 背景与目标

**背景**：HTML 原型已验证核心链路：跟练播放器（火柴人动画演示 + 语音数拍 + 节奏同步）、
15 动作原子库、视频分段跟练、Web Audio 合成配乐、数据记录。产品从"产后专用"泛化为
全人群（5 场景：产后恢复/新手入门/减脂燃脂/塑形增肌/办公拉伸），产后恢复是其中一个场景。

**目标**：
1. 第一用户（产后恢复场景的妈妈）能连续使用 14 天，完整跑通"选场景 → 跟练 → 记录 → 反馈"闭环；
2. 其他 4 个场景的用户也能完成一次完整的跟练（场景泛化验证）；
3. 所有用户数据持久化（IndexedDB），刷新/关闭页面不丢失；
4. 离线可用：核心链路无网络必须可用。

**非目标**（见 §2 Out）：后端/账号/同步、小程序/原生 App、饮食模块、精确卡路里、社交、
B站视频解析下载。

## 2. 范围

### 做（In）
- **F1** 跟练播放器（动画模式）：动作队列 → 计时/计数 → 组间休息 → RPE → 训练小结
- **F2** 动作库：15 动作原子（多维属性/搜索/筛选/详情/进退阶/安全标签）
- **F3** 自建跟练：多选动作 → 生成跟练序列
- **F4** 当天自适应：三个一键降载（只有10分钟/要安静/轻松点）
- **F5** 场景体系：5 场景、开屏问卷、场景切换、每场景推荐课、分场景小贴士
- **F6** 视频跟练：本地视频导入 + 分段编辑器 + 分段跟练 + B站轻量收藏
- **F7** 配乐：Web Audio 合成 4 氛围 + 动作自动切换 + 用户音频绑定
- **F8** 数据记录：训练历史/体重曲线/围度/营养打卡（IndexedDB 持久化）
- **F9** 训练反馈：RPE → 自适应建议文案；练后小结
- **F10** 情绪价值文案体系
- **F11** 健康安全：开屏健康准入、温和模式、DRA 不安全动作自动过滤

### 不做（Out，留 V1/V2）

- 小程序/原生 App（Web 验证后再议）
- 饮食模块一切内容（V1：菜品库/跟做模式/营养联动）
- 精确卡路里计算、买菜、社交
- B站视频解析/下载（**红线**，见宪法）
- 真人视频演示（V0 用火柴人动画；是否拍摄/采购待动作库定型后定）

## 3. 功能需求

### F1 跟练播放器（动画模式）

**队列模型**：`[动作×组数] + 组间休息` 交替。队列可来自：场景推荐课（F5）、自建清单（F3）、
一键降载（F4）、单动作（F2 详情页）。

**演示动画**：每个动作配火柴人 SVG 动画（9 种：march/squat/bridge/pushup/press/plank/
stretch/crunch/deadbug，见附录 C 配乐映射表），**动画周期 = 动作节奏**。
暂停时动画必须定住（`animation-play-state: paused` 级联），不得各练各的。

**次数类动作**（如臀桥 15次×3组）：
- 监听动画 `animationiteration` 事件自动计数，每完成一次计数+1；
- 语音用中文数字数拍（一、二、三…，Web Speech API，`zh-CN`）；
- 满组自动进入组间休息，**不需要用户点"完成本组"**；
- 计数器显示 `已完成/目标`（如 `7 / 15`）。

**计时类动作**（如靠墙静蹲 40秒×3组）：
- 圆环倒计时；到一半时语音"一半了，坚持住"；
- 静蹲/平板等静态动作用"坚持"类动画（抖动/呼吸），不抢注意力。

**通用控制**：暂停/继续、跳过（当前动作或休息）、退出（二次确认"已完成的动作会保留记录"）。
语音播报开关（默认开）。退出/异常中断时，已完成部分必须已写入训练历史。

**结束流程**：全部完成 → RPE 反馈（😌轻松 / 🙂刚好 / 🥵吃力，强制选择，文案注明"不会有人评判你"）
→ 训练小结（用时/动作数/预估消耗≈用时×3.5kcal/分钟，**必须标注"估算"**）
→ 自适应建议文案（三档，见 F9）→ 写训练历史 → 回首页。

### F2 动作库

**15 个动作原子**（全表见附录 A）。每个动作字段：
`name, emoji, demo(动画类型), kind(time/reps), work/reps, sets, rest, tag(部位：全身/臀腿/上肢/核心/放松), lv(1新手友好/2进阶/3挑战), impact(低/中), equip(徒手/小器械), scen[](适用场景), safe[](安全标签), reg(退阶), prog(进阶), cues[](要领)`。

**浏览**：
- 搜索框：名称模糊匹配；
- 筛选：部位（全部/全身/臀腿/上肢/核心/放松）、难度（全部/新手友好/进阶/挑战）；
- **安全过滤开关**（默认开）：按当前场景过滤；关闭后显示全部动作，但 DRA 不安全等标签必须醒目。
  验收硬指标：产后场景 + 安全过滤开时，搜索"卷腹"无结果。

**动作详情弹窗**：大动画演示 + 属性 pills + 动作要领 + 退阶/进阶卡片 + 安全标签 +
DRA 不安全警告条（如有）+ 两个按钮：「＋ 加入清单」「开始跟练 ▶」（单动作跟练）。

### F3 自建跟练

- 动作库页「自建跟练」按钮进入多选模式（行首出现选择圈）；
- 底部浮动栏显示"已选 N 个动作" + 「生成跟练 ▶」；
- 按选择顺序生成队列（沿用各动作默认组数/休息），标题为「自建跟练 · N个动作」；
- 退出多选模式时清空选择。

### F4 当天自适应（一键降载）

首页「今天状态怎么样？」卡片，三个按钮（单选即执行，不二次确认）：
- ⚡ 只有10分钟：本场景前 4 个动作 × 每组 1 组；
- 🤫 要安静低冲击：本场景低冲击动作 ×1组（取前 5）；
- 😮‍💨 轻松点：本场景 lv1 动作 ×1组（取前 5）。
标题分别为「⚡ 10分钟快充 · 跟练」「🤫 安静跟练 · 不打扰宝宝」「😮‍💨 轻松恢复 · 跟练」。
（文案里的"宝宝"在非产后场景下改为中性词，如"不打扰家人"。）

### F5 场景体系

**5 场景**：产后恢复 🍼 / 新手入门 🌱 / 减脂燃脂 🔥 / 塑形增肌 💪 / 办公拉伸 🪑。
每个场景：名称、emoji、一句话描述、推荐课（课程表见附录 B）、分场景小贴士库。

**开屏问卷**（3 步）：
1. 选场景（5 选 1，必选）；若选产后恢复，追加：宝宝月龄（6周以内/6周~6个月/6~12个月/12个月以上）、分娩方式（顺产/剖腹产）；
2. 若产后恢复：医生许可（可以了/还没问过/医生说再等等）；所有场景：运动基础（纯新手/偶尔/经常）；
3. 每次可投入时长（15/20/30分钟）、器械（徒手/小器械）。
校验：每步必选，未选点下一步时 toast 提示，不跳转。

**场景切换**：首页右上角场景 pill，点击二次确认后清空画像、重走问卷。

**温和模式**（产后专属）：医生许可为"还没问过"/"医生说再等等"时，首页显示温和提示横幅
（"先每天散步 20 分钟就很好……练伴会在这里等你"），点击"开始跟练"需二次确认。

**分场景小贴士**：首页小贴士卡按场景轮换（如产后：喂完奶再练更舒服；减脂：别靠饿；办公：每小时起来活动 2 分钟）。

### F6 视频跟练

**本地视频导入**：
- `<input type="file" accept="video/*">` 选择；预览播放器 + 元信息（时长、大小）；
- **持久化**：视频 Blob 存 IndexedDB（`videos` store），刷新/关闭页面后仍在，
  列表展示已导入视频，可删除；
- 合规提示常驻："只导入自己拍摄或有版权的视频"。

**分段编辑器**：
- 「平均切分」：输入 2–12，自动生成 N 段；
- 「手动添加分段」：默认 `0:00 → min(60s, 时长)`；
- 每段可编辑：名称、起止时间（`m:ss` 格式，如 `1:30`，非法输入拒绝并回滚显示）、
  组数（≥1）、休息秒（≥0）、配乐（热身律动/力量节奏/保持专注/放松舒缓 4 选 1）；
- 起止时间钳制在 `[0, 视频时长]`，且 `end > start`（否则自动修正为 `start+30s`）；
- 删除分段；「开始分段跟练 ▶」按钮（无分段时隐藏）。

**分段跟练**：复用 F1 播放器状态机（work/rest/RPE/小结同一套）；
- 每段：`video.currentTime = start`，播到 `end` 自动暂停 → 组间休息 → 下一段；
- 进度条 + `已播/段长` 时间显示；
- 慢放开关：1x ⟷ 0.75x（"跟不上就点慢放，不丢人"）；
- 语音：段名播报（"臀桥，开始"）；不数拍（节奏由视频本身决定）；
- 暂停/跳过/退出与 F1 一致（退出时 video 必须 pause）。

**B站轻量收藏**（红线内）：
- 输入框粘贴 B站链接或 BV 号 → 收藏列表（IndexedDB 持久化）→「去看」一键跳转；
- **不做**视频解析、下载、站内分段；页面常驻红线提示。

### F7 配乐

**合成配乐**（Web Audio API 现场合成，零资源、无版权、离线可用），4 种氛围：
| 氛围 | BPM | 特点 | 适用动作 demo |
|------|-----|------|---------------|
| 热身律动 warmup | 124 | 四底鼓 + 切分镲 + 贝斯 | march |
| 力量节奏 strength | 100 | 鼓 + 军鼓 + 驱动贝斯 | bridge/pushup/press/crunch |
| 保持专注 hold | 92 | 稀疏鼓点 + 长音贝斯，不抢注意力 | squat/plank/deadbug |
| 放松舒缓 stretch | 64 | 无鼓，pad 和弦（Am-F-C-G） | stretch |

- 动作一切换，配乐自动切换（视频分段按该段所选配乐）；
- 暂停/恢复/结束/退出时联动（暂停即停，恢复即续，练完即停）；
- 播放器内 🎵 开关（默认开）；
- **用户音频绑定**：「我的音乐」页为 4 种氛围各绑一个本地音频文件（IndexedDB Blob 持久化）；
  绑定后该氛围优先播放用户音频，否则用合成节拍；可更换/清除；
- 首次初始化 AudioContext 必须在用户手势（点击"开始跟练"）中触发；iOS 静音模式下无声属于系统行为，
  需在播放器内给一行小提示。

### F8 数据记录

全部经 Dexie (IndexedDB) 持久化，刷新不丢失：

- **训练历史**：`{date, title, minutes, count, countUnit(个/段), rpe}`，倒序列表；
- **体重曲线**：折线图（canvas 或轻量图表库自选）；手动 "+ 记录"（prompt/表单，30–150kg 校验，
  非法拒绝并提示）；
- **围度**：腰/臀/大腿三项 + 最新值与趋势（↓/→）；
- **营养打卡**（按日，跨天清零）：水（ml，+250ml 步进，目标 2000ml）、蛋白（g，+10g 步进，目标 90g）、
  钙片（boolean checkbox）；
- **数据导出/删除**：设置页提供"导出全部数据（JSON 下载）"与"删除全部数据（二次确认）"。
  （宪法红线：不上传，单机所有。）

### F9 训练反馈

**练后小结**（RPE 之后）：用时、动作数（个/段）、预估消耗（用时×3.5kcal/分钟，**必须标"估算"**）。

**RPE → 自适应建议**（三档文案，V0 只做文案级呈现；"建议 visibly 改变下一次计划"留 V1）：
- 😌轻松："你恢复得比想象中快！下次可以试试每组多做 2 次，或组间休息缩短 5 秒，循序渐进就好。"
- 🙂刚好："这个强度刚刚好，保持就是胜利。身体正在稳稳地变强。"
- 🥵吃力："没关系，身体正在适应。下次可以把次数减 2 个——先完成，再完美。"

**诚实约束**（宪法第 2 条）：建议文案不得承诺效果（如"下次一定瘦"）；数据没有变化时不得编造进步曲线。

### F10 情绪价值文案体系

文案是功能，不是装饰。要求：
- **禁止**贩卖身材/掉秤焦虑（"再不练就晚了""胖成这样"类一律不得出现）；
- **庆祝"出现"本身**：完成 < 完美；"宝宝午睡的 20 分钟你全部留给了自己，这很了不起"；
- **低落兜底**：体重没动时 → "肌肉在悄悄生长，围度会先给你答案"；选"吃力"时 → 先共情再给建议；
- **语气**：温暖、直接、不爹味；感叹号克制使用；
- 文案集中管理为文案库（`src/content/copy.ts` 之类），不得散落在组件里硬编码，
  方便后续按场景扩展。

### F11 健康安全

- **开屏健康准入**（F5 问卷）：产后场景必答月龄/分娩方式/医生许可；
- **温和模式**：医生未许可 → 首页横幅 + 跟练二次确认（F5）；
- **自动过滤**：DRA 不安全动作在产后场景默认不可见（F2 验收硬指标）；
- **常驻提示**：播放器底部"如有头晕、恶心、伤口不适请立刻停止"；动作库页"有不适立刻停止 · 必要时咨询医生"；
- **哺乳期约束文案**（产后场景）：不节食、练前练后补水、喂完奶再练更舒服；
- **不做医疗判断**：所有健康相关文案止于"建议咨询医生"，不得出现诊断性表述。

### F12 数据层

- Dexie.js (IndexedDB)，见 ADR-001。Schema（v1）：

```ts
db.version(1).stores({
  profile:   'id',            // {id:'me', scenario, babyAge?, birth?, cleared?, base, minutes, equip}
  workouts:  '++id, date',    // {date, title, minutes, count, countUnit, rpe}
  measures:  '++id, date, kind', // {date, kind:'weight'|'waist'|'hip'|'thigh', value}
  nutrition: 'date',          // {date, waterMl, proteinG, calcium: boolean}
  videos:    '++id, createdAt', // {name, size, duration, blob: Blob, segments:[{name,start,end,sets,rest,style}]}
  audioBinds:'style',         // {style: 'warmup'|'strength'|'hold'|'stretch', name, blob: Blob}
  bvFavs:    '++id, createdAt' // {bvid, url}
});
```

- 所有写操作走 Dexie 事务；Blob 存取注意内存（播放时用 `URL.createObjectURL`，关闭时 `revokeObjectURL`）；
- 首屏不得被数据层阻塞：库初始化异步，UI 先渲染骨架。

## 4. 非功能需求

- **移动端优先**：375–430px 为基准视口；桌面端居中 max-width 430px 展示；
- **性能**：4G 下首屏可交互 < 2s；动画 60fps 为目标，低端机可降级（关闭火柴人以外的装饰动画）；
- **离线**：核心链路（F1/F2/F5/F8 查看与记录）无网络必须全可用；B站跳转除外；
- **无登录**：打开即用，不设账号墙；
- **PWA**：V0 不强求 Service Worker 缓存策略，但 `index.html` 必须含移动端 meta，
  「添加到主屏幕」后可全屏打开；
- **兼容**：iOS Safari 16+、Android Chrome 近 2 年版本；Web Speech / Web Audio 不可用时
  功能降级（静默跟练），不得白屏、不得报错阻塞。

## 5. 验收标准

1. 开屏选产后恢复 + 医生许可"再等等" → 首页出现温和模式横幅；点"开始跟练"弹出二次确认。
2. 开屏选减脂燃脂 → 首页推荐课为「燃脂循环 · 跟练」，课程动作数/时长/消耗正确计算展示。
3. 产后场景 + 安全过滤开：动作库搜索"卷腹"无结果；关闭安全过滤后可见，且带红色 "DRA不安全" 标签。
4. 臀桥 15次×3组跟练：语音用中文数字数拍，满 15 次自动进组间休息，全程无需手动点"完成本组"。
5. 靠墙静蹲 40秒：圆环倒计时正常；20 秒时语音播报"一半了，坚持住"。
6. 播放中点暂停：动画、倒计时、音乐、语音全部停止；点继续：全部恢复，无跳秒。
7. RPE 选"🥵吃力" → 小结出现降载建议文案；选"😌轻松" → 出现加量建议文案。
8. 动作库多选 3 个动作 → 点"生成跟练" → 播放器按选择顺序执行，标题为「自建跟练 · 3个动作」。
9. 首页点"⚡ 只有10分钟" → 生成 ≤4 个动作×1组 的队列并直接开练。
10. 导入一个 mp4 → 平均切分 4 段 → 开始分段跟练：每段播到 end 自动暂停 → 休息 30s → 下一段；0.75x 慢放生效。
11. 刷新页面后：训练历史、体重、围度、营养、视频（含 Blob 可播放）、音频绑定、B站收藏全部仍在。
12. 给"力量节奏"绑定一首本地 mp3 → 做力量动作时播放该 mp3 而非合成节拍；清除绑定后恢复合成。
13. 开飞行模式：跟练、动作库浏览、历史查看、体重记录全部可用（B站跳转除外）。
14. 体重录入 `abc` / `500` → 拒绝并提示；录入 51.0 → 曲线更新，首页体重同步。
15. 切换场景到"办公拉伸" → 首页推荐课、动作库过滤、小贴士全部变为办公场景；产后安全横幅消失。
16. `npm run build` 通过；控制台无 error；文案库无硬编码散落（抽查 3 处）。

## 6. 里程碑（编码 Agent 可合并但不可跳过验证）

- **M1**：数据层（Dexie schema + 读写封装）+ 动作库数据（15 动作全表）+ 动作库页（搜索/筛选/安全开关/详情弹窗）
- **M2**：跟练播放器（动画模式：演示/计数/计时/语音/暂停跳过）+ 配乐引擎（4 氛围合成 + 自动切换 + 开关）
- **M3**：场景体系（问卷/切换/推荐课/温和模式/分场景小贴士）+ 自建跟练 + 当天自适应 + 首页
- **M4**：视频跟练（导入/分段编辑器/分段跟练/慢放）+ B站收藏 + 用户音频绑定
- **M5**：数据页（历史/体重曲线/围度/营养打卡/导出删除）+ RPE 反馈 + 情绪价值文案库
- **M6**：全量验收（§5 共 16 条）+ 离线验证 + 构建通过

**交付顺序说明**：M1–M2 是第一个可交付切片（能看动作、能跟练）；M3–M4 随后；M5–M6 收尾。
不得为了"一次到位"把 6 个里程碑并成一个大提交。
